Characters go here as rigged humanoid .glb files; the profile lists every file found in this folder.

The bundled characters are Quaternius "Ultimate Animated Characters" (CC0), and they move with the
clips stored inside each file (Idle, Walk, SitDown, ...).

Other files (for example Mixamo FBX characters) can be kept in the "backup" folder or here; they are not committed
to the repository. Walk clips for Mixamo rigs go in public/models/animations/walk.
